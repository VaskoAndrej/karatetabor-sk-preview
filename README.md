# Karate tábor Tesáre

Prezentačný statický web pre Karate tábor Tesáre 2027.

Web nevyžaduje zostavenie ani serverovú databázu. Verejná časť je pripravená na GitHub Pages. Prihlasovanie do archívu je zatiaľ iba používateľské rozhranie a pred reálnym použitím musí byť pripojené k zabezpečenému backendu.
